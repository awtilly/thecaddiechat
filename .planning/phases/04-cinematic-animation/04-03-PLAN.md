<objective>
Fix Lightbox.astro lifecycle event so it re-initializes after View Transitions SPA navigation.

Purpose: Lightbox.astro is the only remaining component using `DOMContentLoaded`, which fires once on initial page load and never again during ClientRouter SPA navigation. This means clicking images on course article pages (8 pages) and camera-roll produces no effect if the user navigated there via a link rather than a full page load. This directly undermines TRNS-01 (View Transitions compatibility).

Output: Lightbox.astro uses `astro:page-load` with `{ once: false }`, ensuring lightbox functionality works on every page load -- both initial and SPA navigation.
</objective>
