  <files>scripts/validate-images.mjs</files>
  <action>
Create `scripts/validate-images.mjs` that runs AFTER `npm run build` and checks the `dist/` output for:

1. **FNDN-03a: Responsive srcset present** -- At least one HTML file in dist/ contains a `srcset=` attribute. Use glob to find `dist/**/*.html` and grep for `srcset=`. Report count of files with srcset.
2. **FNDN-03b: WebP or AVIF formats generated** -- Check that `dist/_astro/` contains `.avif` or `.webp` files. Report count.
3. **FNDN-03c: No hardcoded /assets/images paths** -- Ensure no HTML file contains `src="/assets/images`. This catches broken hardcoded paths that bypass Astro optimization. Fail if any found.
4. **FNDN-03d: No external Unsplash URLs** -- Ensure no HTML file contains `unsplash.com`. Fail if any found.
5. **FNDN-04a: No Google Fonts import** -- Ensure no HTML or CSS file contains `fonts.googleapis.com`. Fail if any found.
6. **FNDN-04b: Self-hosted font files** -- Check that `dist/_astro/` contains `.woff2` files. Report count.

Script should:
- Use Node.js fs/path/glob modules (no external deps)
- Print clear PASS/FAIL for each check with counts
- Exit code 0 if all pass, 1 if any fail
- Use `import { glob } from 'node:fs'` or manual recursive readdir if glob unavailable -- keep it simple with fs.readdirSync recursive

Do NOT add a package.json script entry yet -- that will be done in Task 2.
  </action>
  <verify>

  </verify>
