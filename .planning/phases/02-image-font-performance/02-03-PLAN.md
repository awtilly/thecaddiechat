**Complete rewrite of src/pages/camera-roll/index.astro:**

Keep the existing PageLayout wrapper with the same title, description, pageTitle, pageSubtitle, and sectionLabel props. Keep the CtaBanner at the bottom. Replace everything in between.

**Frontmatter -- import and organize images:**
```astro
---
import PageLayout from '../../layouts/PageLayout.astro';
import { Image } from 'astro:assets';
import CtaBanner from '../../components/CtaBanner.astro';
import Lightbox from '../../components/Lightbox.astro';

// Glob import all camera roll images
const allImages = import.meta.glob<{ default: ImageMetadata }>(
  '/src/assets/images/camera-roll/*.jpg',
  { eager: true }
);

// Group by film roll prefix (first 9 digits of filename)
const rollMap = new Map<string, { src: ImageMetadata; filename: string }[]>();
for (const [path, module] of Object.entries(allImages)) {
  const filename = path.split('/').pop()!.replace('.jpg', '');
  const rollId = filename.substring(0, 9);
  if (!rollMap.has(rollId)) rollMap.set(rollId, []);
  rollMap.get(rollId)!.push({ src: module.default, filename });
}

// Sort each roll's images by filename
for (const images of rollMap.values()) {
  images.sort((a, b) => a.filename.localeCompare(b.filename));
}

// Convert to array and sort rolls by their ID
const rolls = [...rollMap.entries()]
  .sort(([a], [b]) => a.localeCompare(b))
  .map(([id, images], index) => ({
    id,
    label: `Roll ${index + 1}`,
    count: images.length,
    images,
  }));
---
```

**Template -- gallery sections by roll:**
For each roll, render a section with:
- A header showing `<h2>{roll.label}</h2>` and `<span>{roll.count} Frames</span>` (same styling as current gallery-section-header)
- A CSS Grid of images using `<Image>` with:

  - `sizes="(max-width: 768px) 50vw, (max-width: 1280px) 33vw, 25vw"`
  - `loading="lazy"` on all images
  - `data-lightbox` attribute for lightbox support
  - `alt` set to `"Film photograph {index + 1} from {roll.label}"` (descriptive but generic since we don't know subjects)

**Include Lightbox component** at the bottom (before closing PageLayout or after CtaBanner). The existing Lightbox.astro component queries `img[data-lightbox]` from the DOM and provides navigation.

Keep the existing `.gallery-section`, `.gallery-section-header` class names and styling patterns -- they're already defined in PageLayout or inherited from the current page.
