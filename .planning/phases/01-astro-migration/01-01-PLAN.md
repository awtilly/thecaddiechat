**Step 2: Initialize Astro project at repo root.**

**Step 3: Configure astro.config.mjs** exactly as specified in the research:
```javascript

  output: 'static',

  integrations: [mdx()],
```

**Layouts (read existing HTML for structure patterns):**

1. **BaseLayout.astro** — HTML shell. Props: `title` (string), `description` (optional string). Imports `../styles/global.css`. Renders `<!DOCTYPE html>`, `<html lang="en">`, `<head>` with charset, viewport, title, description meta, favicon link, and Google Fonts preconnect/import link. `<body>` wraps `<slot />`. See research code example for BaseLayout.

2. **PageLayout.astro** — Standard page wrapper. Props: `title` (string), `description` (optional string), `pageTitle` (optional string), `pageSubtitle` (optional string). Wraps content in BaseLayout. Renders Nav, optional page-header section (with `.page-header` class containing h1 + optional subtitle), `<main>` with `<slot />`, then Footer. Extract `.page-header` styles from existing CSS into scoped `<style>`.

3. **ArticleLayout.astro** — Chronicle article wrapper. Props: from chronicle frontmatter (`title`, `description`, `date`, `heroImage`, `meta`, `prev`, `next`). Wraps in BaseLayout. Renders Nav, article-header section (hero image background, title, meta line, date), `<article class="article-body">` with `<slot />`, ArticleNav (prev/next), Footer. Extract `.article-header`, `.article-body`, `.article-meta`, `.article-date` styles from existing CSS. Use `:global()` for styles that must reach MDX-rendered content inside the article body (paragraphs, headings, images, blockquotes).

4. **CourseLayout.astro** — Course article wrapper. Props: from course frontmatter (`title`, `description`, `architect`, `year`, `location`, `heroImage`, `courseNumber`, `style`, `prev`, `next`). Wraps in BaseLayout. Renders Nav, course-hero section (full-bleed hero image, course number badge, title, architect + year + location details), `<article class="course-body">` with `<slot />`, ArticleNav (prev/next), Lightbox, Footer. Read a representative course HTML (e.g., `friars-head/index.html`) to extract the course-hero structure and all course-specific styles. Include scoped styles for `.course-hero`, `.course-info`, `.course-badge`, and use `:global()` for course-body content styles.
